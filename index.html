Reminders setup

A web app can’t write to Apple Reminders on its own. A two-step Shortcut bridges it: Phil hands it the text, the Shortcut files the reminder. Build it once, then every “Remind me” is a single tap.

  1. Open Shortcuts, tap +, and name the shortcut exactly Phil Reminder.
  2. Tap the ⓘ details button and turn on Show in Share Sheet. This lets it receive text.
  3. Add the action Get Dates from Input. Leave its input as Shortcut Input.
  4. Add Add New Reminder. Set the reminder text to Shortcut Input, tap Remind Me → At Time, and pick the Dates variable.
